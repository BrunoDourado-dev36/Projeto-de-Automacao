# 🤖 Projeto de Automação com Python

Projeto desenvolvido em Python com o objetivo de automatizar tarefas repetitivas utilizando a biblioteca **PyAutoGUI**.

A automação simula ações do usuário no computador, como abrir o navegador, acessar um sistema web, realizar login e executar tarefas dentro da aplicação.

> 🚧 Projeto em desenvolvimento — novas etapas e melhorias serão adicionadas conforme o aprendizado.

---

## 📌 Sobre o Projeto

Este projeto foi desenvolvido como uma forma de praticar **Python, automação de tarefas e lógica de programação** em um cenário mais próximo de uma aplicação real.

A ideia é criar uma automação capaz de:

- 🌐 Abrir o navegador;
- 🔗 Acessar um sistema web;
- 🔐 Realizar login automaticamente;
- 📊 Trabalhar com dados armazenados em CSV;
- 📝 Cadastrar produtos;
- 🔄 Repetir tarefas automaticamente;
- ⚙️ Reduzir tarefas manuais e repetitivas.
